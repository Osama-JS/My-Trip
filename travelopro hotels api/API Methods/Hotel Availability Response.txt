Hotel Availability Response
Hotel Search Response Elements

Element	Description
status	Indicate the status of the request.
sessionId	Indicates the sessionId for which the search results were requested. You must use this sessionId to make the next API request.
moreResults	Indicates whether all the requested suppliers have returned all the search results. If this field returns true, this means that more results are available from some suppliers and another more_hotel_results API call can be made to retrieve the updated list of search results. If this field returns false, this means that all the search results from all the requested suppliers are already provided in the current result set.
nextToken	Every result set that the hotel_availabilty_search API returns has a unique token. This token enables you to retrieve any previously missed or timed-out search results based on the token provided. To get progressive results, use the value returned in this field as the value of the token parameter in the next more_hotel_results API call.
totalResults	Indicates total number of hotel results count.
supplierid	Unique ID of the suppliers.
twxHotelId	Unique ID for this specific hotel.
hotelId	Unique hotel ID that identifies a specific hotel. This is the unique ID that has assigned to the hotel.
TokenId	Indicated the unique token id provided.
productId	Contains the Product ID from whom you want to obtain the list of room options for a specific hotel (hotelId), along with their rates. You can obtain the list of Product IDs that have successfully returned results from the productId field in the Hotel Search Results API's response.
currency	3-character ISO code that indicates the currency in which the rate is returned.
price	Base price of the room.
hotelName	Name of the hotel as provided by the supplier.
address	Address of the hotel as provided by the supplier.
latitude	The latitude coordinate for the hotel.
longitude	The longitude coordinate for the hotel.
thumbNailUrl	The image of the hotel.
hotelRating	Contains rating information for the hotel.
phone	Phone number of the hotel.
email	Email of hotel.
postalCode	Zipcode/Postalcode of hotel.
facilities	Facilities provided by the hotel.
city	City of hotel.
locality	Region name where hotel located.
distanceValue	Distance of hotel from center of city in KM.
distanceUnit	Unit of distance.
fareType	Rate class of hotel Refundable/Non-Refundable.
propertyType	Indicates the the type of accomodation.
tripAdvisorRating	Trip advisor rating count.
tripAdvisorReview	Trip advisor review count.
