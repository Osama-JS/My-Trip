Hotel Filter
Hotel filter API allows you to retrieve hotel search results based on the filter request fields that based on hotel search response.

This API returns the hotels that are available in the given criteria of filtration parameters. To get progressive results for particular session, use the value of the sessionId field from the appropriate Hotel Search Results API’s response.

Hotel Filter: Request

Method	URL
POST	https://travelnext.works/api/hotel-api-v6/filterResults
Hotel Filter Elements

Element	Format	Description	Required
sessionId	String	Use the sessionId that was returned in the Hotel search result API's response.	REQUIRED
maxResult	Integer	Send how many results required in filter search response.	REQUIRED
filters	Array	Array of all filteration parameters.	REQUIRED
price	Array	Array of minmum and maximum price range.	OPTIONAL
rating	String	Pass the rating values are ranging from 0 to 5. Ex. "0,1,2,3,4,5".	OPTIONAL
tripadvisorRating	String	Pass the rating values are ranging from 0 to 5. Ex. "0,1,1.5,2,2.5,3,3.5,4,4.5,5".	OPTIONAL
hotelName	String	Use hotel initial name to search from the response.	OPTIONAL
faretype	String	Filter results by Refundable/ Non-Refundable.	OPTIONAL
propertyType	String	Filter by property type which comes from hotel search response. Ex. "HOTELS, RESORTS,APARTMENTS".	OPTIONAL
facility	String	Filter by facility which comes from hotel search response. Ex. "WLAN access,Room Service, Laundry Service".	OPTIONAL
sorting	String	Sort results by rating, price, distance from center, alphabetic.
Ex. "price-low-high,"price-high-low","rating-low-high","rating-high-low","alpha-A-Z","alpha-Z-A","distance-low-high","distance-high-low"	OPTIONAL
locality	String	Filter by locality/region which comes from hotel search response.	OPTIONAL
Sample Hotel Filter Request

{
  "sessionId":"TVRVNE1qSTJNRFkzTUY4ek9EQmZNVEkxTGprNUxqSTBNUzR5TkE9PV8w",
  "maxResult":20,
  "filters":{
    "price":{
      "min": 100,
      "max": 500000
    },
    "rating":"1,2,3,4,5",
    "tripadvisorRating":"1,1.5,2,2.5,3,3.5,4.5,5",
    "hotelName":"Hotel",
    "faretype": "Non-Refundable",
    "propertyType":"HOTELS",
    "facility":"Internet access,Air conditioning",
    "sorting": "price-low-high",
    "locality":"region_name1,region_name2"
  }
}
