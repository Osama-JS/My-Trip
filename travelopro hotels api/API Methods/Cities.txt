Cities
This API returns the city details, which is needed in the geo-location wise and city wise hotel search.

Request

Method	URL
GET	https://travelnext.works/api/hotel-api-v6/cities?user_id=<user_id>&user_password=<user_password>&ip_address=<p_address>&access=Test
