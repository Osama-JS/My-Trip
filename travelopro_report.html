عمليات API الطيران (aeroVE5)

# العملية نقطة النهاية حالة التنفيذ موقع التنفيذ ملاحظات
🔍 مرحلة البحث والتحقق
1 Flight Search
البحث عن رحلات		 /availability ✅ مكتمل TraveloproService::searchFlights()
FlightController		 يدعم One-Way/Round-Trip/Multi-City. يطبق هامش الربح. يحفظ session_id.
2 Validate Fare
التحقق من السعر قبل الحجز		 /revalidate ✅ مكتمل TraveloproService::validateFare() يُعيد تطبيق هامش الربح. يستخدم fare_source_code وflight_session_id.
3 Airport List
قائمة المطارات		 /airport_list ✅ مكتمل TraveloproService::getAirportList()
syncAirports()		 يدعم EN/AR. Cache 24 ساعة. Fallback للمطارات الرئيسية.
4 Airline List
قائمة شركات الطيران		 /airline_list ✅ مكتمل TraveloproService::getAirlineList() Cache 24 ساعة.
5 Fare Rules
قواعد التعرفة		 /fare_rules ✅ مكتمل TraveloproService::getFareRules()
FlightController		 متاح كـ API endpoint.
6 Extra Services
أمتعة / مقاعد / وجبات		 /extra_services ⚠️ جزئي TraveloproService::getExtraServices() الجلب منفذ لكن لا يوجد UI لاختيار الخدمات قبل الحجز.
📋 مرحلة الحجز وإصدار التذاكر
7 Create Booking (PNR)
إنشاء الحجز		 /booking ⚠️ جزئي TraveloproService::createBooking()
FlightController		 ⚠️ بنية paxDetails قد تختلف عن الوثيقة — تحتاج مراجعة (تغليف مزدوج).
8 Order Ticket
إصدار التذكرة		 /ticket_order ✅ مكتمل TraveloproService::orderTicket()
PaymentWebController		 يُشغَّل تلقائياً بعد نجاح الدفع. يستخرج rقم eTicket ويحفظه.
9 Trip Details
تفاصيل الرحلة		 /trip_details ✅ مكتمل TraveloproService::getTripDetails() لمزامنة حالة الحجز.
10 Search Post-Ticket Status
متابعة حالة التذكرة		 /post_ticket_status ✅ مكتمل TraveloproService::searchPostTicketStatus() لمتابعة التذاكر بعد الإصدار.
11 Booking Notes
ملاحظات الحجز		 /booking_notes ✅ مكتمل TraveloproService::addBookingNotes() متاح.
❌ مرحلة الإلغاء والاسترداد
12 Cancel Booking /cancel ✅ مكتمل TraveloproService::cancelBooking() يحدث حالة الحجز في DB.
13 Void Quote
عرض رسوم الإلغاء الفوري		 /void_quote ✅ مكتمل TraveloproService::voidQuote() متاح.
14 Void Ticket
إلغاء فوري للتذكرة		 /void_ticket ✅ مكتمل TraveloproService::voidTicket() يرسل paxDetails مع eTicket.
15 Refund Quote /refund_quote ✅ مكتمل TraveloproService::refundQuote() متاح.
16 Refund Ticket /reissue_ticket
⚠️ URL مشبوه		 ✅ مكتمل TraveloproService::refundTicket() الوثيقة تُدرج Refund تحت endpoint مشتركة مع Reissue — يحتاج توضيح من المورد.
17 Reissue Quote /reissue_quote ✅ مكتمل TraveloproService::reissueQuote() متاح.
18 Reissue Ticket
إعادة إصدار تذكرة		 /reissue_ticket ✅ مكتمل TraveloproService::reissueTicket() متاح.

عمليات API الفنادق (hotel-api-v6)

# العملية نقطة النهاية حالة التنفيذ موقع التنفيذ ملاحظات
🔍 مرحلة البحث والتصفية
1 Hotel Search
البحث عن فنادق		 /hotel_search ✅ مكتمل TraveloproHotelService::search()
HotelController		 يدعم البحث بالاسم/إحداثيات/كود المدينة. توزيع غرف ذكي. يحفظ النتائج في Session.
2 Hotel Filter
تصفية النتائج		 /filterResults ⚠️ جزئي TraveloproHotelService::filter() منفذ في الخدمة لكن غير متكامل كاملاً مع الواجهة الأمامية.
3 More Results Pagination
تحميل المزيد		 /moreResultsPagination ⚠️ جزئي TraveloproHotelService::nextToken() الكود موجود لكن التحقق من تكامله مع الواجهة غير مؤكد.
4 Cities
قائمة المدن		 /cities ✅ مكتمل TraveloproHotelService::getCities()
syncCities()		 يدعم EN/AR. Fallback للمدن الرئيسية. يُشغَّل من لوحة التحكم.
5 Languages /languages ✅ مكتمل TraveloproHotelService::getLanguages() متاح.
🏨 مرحلة تفاصيل الفندق والغرف
6 Get Hotel Content
تفاصيل الفندق		 /hotelDetails ✅ مكتمل TraveloproHotelService::getHotelContent() يدعم EN/AR ويسجل مفاتيح الاستجابة.
7 Room Rates
أسعار الغرف		 /get_room_rates ✅ مكتمل TraveloproHotelService::getRoomRates() يطبق هامش الربح على perBookingRates و RoomResults.
8 Check Room Rates (Rate Rules)
التحقق من الغرفة		 /get_rate_rules ✅ مكتمل TraveloproHotelService::checkRoomRates() يُشغَّل قبل الحجز للحصول على rateBasisId. يطبق الهامش على TotalFare.
9 Hotel Static Content
المحتوى الثابت		 /staticContent ❌ غير منفذ — لا يوجد تنفيذ. يُستخدم لجلب صور ووصف الفنادق مسبقاً لتسريع التصفح.
📋 مرحلة الحجز والتأكيد
10 Hotel Booking
إنشاء الحجز		 /hotel_book ✅ مكتمل TraveloproHotelService::book()
PaymentController
PaymentWebController		 يُحوّل البيانات الداخلية للهيكل الرسمي. يُنفَّذ تلقائياً بعد الدفع.
11 Hotel Booking Details
تفاصيل الحجز		 /bookingDetails ✅ مكتمل TraveloproHotelService::getBookingDetails()
BookingController::syncHotelBookingStatus()		 لمزامنة الحالة مع المورد.
❌ مرحلة الإلغاء
12 Get Cancellation Charge
رسوم الإلغاء		 /hotel_cancel_charge ✅ مكتمل TraveloproHotelService::getCancelCharge() يُعرض للمستخدم قبل تأكيد الإلغاء.
13 Cancel Booking /cancel ✅ مكتمل TraveloproHotelService::cancel()
BookingController::cancelHotel()		 يحدث حالة الحجز في DB.
14 More Hotel Filter + Pagination /moreFiltersPagination ❌ غير منفذ — موثق في API لكن لا يوجد تنفيذ.

المشكلات والانحرافات عن الوثيقة الرسمية

خطورة عالية
🔴 [فنادق] الـ sessionId قد يُفقد بين مراحل الحجز
الوثيقة تؤكد أن sessionId يجب تمريره في جميع مراحل الحجز (Search → Room Rates → Rate Rules → Booking). الكود يبحث عنه في أماكن متعددة مما يشير لعدم اليقين من هيكل الاستجابة الفعلي.
// المشكلة: البحث في أماكن متعددة = عدم يقين من هيكل الاستجابة $sessionId = $statusField['sessionId'] ?? $statusField['session_id'] ?? null; // ثم في normalizeHotelResults: $sessionId = $response['sessionId'] ?? $response['session_id'] ?? null;
الحل المقترح: تسجيل الاستجابة الكاملة لحجز فندق حقيقي وتثبيت المسار الصحيح للـ sessionId.
خطورة عالية
🔴 [طيران] بنية paxDetails في الحجز قد تخالف الوثيقة
الوثيقة تُوضح أن paxDetails هو مصفوفة مباشرة، لكن الكود يُغلّف النتيجة داخل مصفوفة إضافية.
// الكود الحالي (قد يكون خاطئاً — تغليف مزدوج): 'paxDetails' => [ $this->formatPaxDetails($data['passengers']) ] // الوثيقة تتوقع: 'paxDetails' => $this->formatPaxDetails($data['passengers'])
تحذير
🟡 [طيران] بناء URLs عبر string replace — نهج هش
الكود يبني جميع URLs بتحويل كلمة "availability" في الـ Base URL، مما يجعل أي تغيير بسيط في الـ URL يكسر كل شيء.
$url = str_replace('availability', 'booking', $this->url); $url = str_replace('availability', 'ticket_order', $this->url); // الأفضل: تعريف ثوابت لكل endpoint بشكل صريح
أمان
🟡 [فنادق] تعطيل التحقق من SSL في الاتصال مع Travelopro
الكود يستخدم Http::withoutVerifying() في TraveloproHotelService. مقبول للتطوير لكن خطر أمني كبير في الإنتاج.
$response = Http::withoutVerifying()->connectTimeout(60)->timeout(120)->post($url, $payload);
الحل: استخدام Http::withOptions(['verify' => '/path/to/cacert.pem']) في الإنتاج. (المشروع يحتوي بالفعل على cacert.pem!)
تحذير
🟡 [طيران] Extra Services — جلب بدون واجهة اختيار للمستخدم
الوثيقة توفر API كاملة للخدمات الإضافية (أمتعة، مقاعد، وجبات) وتدعم إرسالها في ExtraServiceOutbound/Inbound. الكود يدعم الإرسال لكن لا توجد واجهة مستخدم لعرض الخيارات.
ملاحظة
🔵 [طيران] passportIssueDate غير مُجمَّع ولا مُرسَل
الوثيقة تُشير إلى أن passportIssueDate إلزامي إذا كانت IsPassportFullDetailsMandatory = true في استجابة Validate Fare. الكود لا يتحقق من هذا الشرط ولا يجمع هذا الحقل.
ملاحظة
🔵 [فنادق] Hotel Static Content API غير مُنفَّذ
الوثيقة تتضمن /staticContent لجلب صور مفصّلة وأوصاف ثابتة للفنادق. غياب هذا يعني الاعتماد الكلي على البيانات الديناميكية (البحث) وهي أقل تفصيلاً وأبطأ.

التوصيات والأولويات

🔴 إصلاحات عاجلة (P0 — فورية)

إعادة هيكلة بناء URLs باستخدام ثوابت بدلاً من string replace

بناء واجهة مستخدم لاختيار Extra Services (أمتعة/مقاعد) قبل حجز الطيران
